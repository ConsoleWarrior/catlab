# Котолаборатория — заметки проекта

## Язык общения (ВАЖНО, для всех агентов)
- **Всегда отвечай на русском** — все ответы, пояснения и сообщения, даже если код, ошибки или логи на английском.

## Локальный dev-сервер (ВАЖНО, для всех агентов)
- **В конце каждого ответа давай ссылку на локальный сервер:** http://localhost:5199
- Перед тем как дать ссылку, **проверь, что сервер запущен** (например `Invoke-WebRequest http://localhost:5199 -UseBasicParsing -TimeoutSec 4`).
- Если сервер **не отвечает — запусти его** в фоне: `npx vite --port 5199 --strictPort` (порт 5199 — конвенция проекта, его же использует `scripts/screenshots.mjs`).
- Сервер «пропадает» обычно из-за перезагрузки ПК — это не баг, просто подними заново.

## Стек / структура
- Vite + TypeScript + Pixi.js (v8). Точка входа `src/main.ts` → `src/ui/game.ts`.
- Игровое ядро (чистые функции, тестируемо) — `src/game/*`; генетика/каталог — `src/genetics/*`; UI на Pixi — `src/ui/*`.
- Баланс правится в `src/game/config.ts`, не в логике.
- Тесты — vitest (`npm run test:run`), типы — `npm run typecheck`.
